built for the podium

One composition. Every screen.

Conference screens are a graveyard of mismatched resolutions. Most decks were authored for one screen and break on the rest — text reflows, a chart slips off the edge, the hero number wraps. better-slides is a fixed composition authored at 1920×1080 and scaled as one unit: it letterboxes instead of reflowing. Plug in, present, don't think about it.

an agent skill

Point your agent at it.

Works with Claude Code and any coding agent that can read a repo and run a shell. Point it at your talk; get back one portable .html file.

  1. 01BriefPurpose, length, register — plus a topic, rough notes, finished material, or a .pptx to convert.
  2. 02Method passThe agent applies the Speaker Playbook: finds your one idea, your hero slide, your landing.
  3. 03StylePick a performance style from generated live previews.
  4. 04BuildOne self-contained HTML deck, themed, with motion and (optionally) sound wired in.
  5. 05Perform / sharePresent it, edit inline, deploy to a URL, or export a PDF.

The performance layer

GSAP-driven timed reveals, staggered builds, and an omt ("one more thing") finale recipe. Optional sound design — applause beds, swooshes, chimes — through the Web Audio API.

Inline editing

Press e in any deck, click any text and type, Ctrl/Cmd+S downloads the edited file. Fix a typo at the venue with nothing but a browser.

PPTX conversion

Point it at a .pptx; it extracts every slide, note and image, then re-authors the content as a performance — not a 1:1 port. The playbook applies.

Share scripts

One command to deploy to a live URL, export a print-faithful PDF, or capture the social share card straight from the rendered title slide.

Event-proof stage engine

Keyboard / swipe / deep-link nav, a glass control menu, and a progress bar — on a stage that letterboxes instead of reflowing, on every screen.

Zero dependencies

One HTML file (plus optional audio assets). No npm, no build step, no framework. Works in 10 years.

six performance styles

Not themes. Design systems.

Each one is typography, palette, motion grammar, and a sound palette. Every one has a live demo — a genuine short talk with its own argument, because a style demo that has nothing to say isn't demonstrating the point. Press → to advance, m for sound.

NoirLaunches, vision talks, founder pitches↗ Obsidianapple.com after dark — expensive and considered↗ CupertinoStory talks, career retrospectives↗ SpotlightMeetups, teaching, lightning talks↗ TerminalDev-tool launches, security, hackathons↗ BroadsheetResearch, strategy, essays-as-talks↗

These are real title slides, captured from the running decks — not mockups. Each style is a full design.md with motion grammar and sound palette, and the skill always offers a custom wildcard when none of these fits the brief.

one more thing…

It tells you what to say.

Design without a point of view is slop. Every other AI slide tool stops at how it looks. better-slides ships The Speaker Playbook — a built-in methodology for what to actually put on stage — and the agent applies it before it writes a single slide.

Read the Playbook ▸
  1. 01Distill to one ideaOne idea, said in one breath. If it doesn't fit in a breath, it isn't one idea yet.
  2. 02Narrative over dataOptimize for what the room feels, not for what the slide proves.
  3. 03One huge numberThe money moment. Once per deck, and make it enormous.
  4. 04A hero slide worth screenshottingThe hero slide does the spreading. Build one visual worth photographing.
  5. 05Stick the landingDon't vanish. Leave the room itching to act tonight.
install

Two lines in Claude Code.

01 /plugin marketplace add https://github.com/hanley-tech/better-slides
02 /plugin install better-slides@better-slides

Run the second one as a separate message. Then use it with /better-slides:better-slides and tell it what your talk is about.

Manual skill: git clone https://github.com/hanley-tech/better-slides.git ~/.claude/skills/better-slides, then type /better-slides.
Any other coding agent: send it this repo link and ask it to use the better-slides skill — it should start from SKILL.md.
